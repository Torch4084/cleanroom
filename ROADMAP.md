# Roadmap

Near-term improvements that would make CleanRoom more useful:

- Add a dry-run view before launching bootstrap or `systemd-nspawn` commands
- Improve status and error messaging for failed privileged commands
- Expand unit tests for command construction, path handling, and AI prompt behavior
- Add integration notes for common distributions and terminal emulators
- Support an explicit per-user or custom machines directory workflow
- Improve desktop integration and packaging
- Add screenshots and short demo media to the README
- Improve visual feedback while long-running actions are in progress
- Add safer AI-assisted workflows such as package set refinement and command review
